One word for my Wi-Fi: **Ghosting**.

The signal vanishes mid-call, mid-show, mid-game — no warning, no
explanation, just gone. Like being ghosted, but by your own router.

`main.ts` writes the word to `/output/entry.txt`. No network, no
dependencies, no input files. Run it with Node 22:

```sh
node main.ts
```
