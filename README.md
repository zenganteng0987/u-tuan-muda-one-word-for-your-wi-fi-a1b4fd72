One word for my Wi-Fi: **Situationship**. It connects, vanishes mid-call, comes back like nothing happened, and never commits — a relationship with my router that has all the drama and none of the reliability. `main.ts` writes that single word to `/output/entry.txt`, with no network, no dependencies, and no input files.

## Run it

```sh
node main.ts
```
